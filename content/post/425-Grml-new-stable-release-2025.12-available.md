We are proud to announce our new stable release 🚢 version 2025.12, code-named ['Postwurfsendung'](https://grml.org/faq/#releasename)!

Grml is a bootable live system (Live CD) based on Debian. Grml 2025.12 brings you fresh software packages from Debian testing/forky, enhanced hardware support and addresses known bugs from previous releases.

Like in the previous release 2025.08, Live ISOs 📀 are available for 64-bit x86 (`amd64`) and 64-bit ARM CPUs (`arm64`).

### grml-live changes

For this release a number of internal changes to our build-tool [grml-live](https://github.com/grml/grml-live/) were implemented.
If you remaster Grml ISOs or build your own, please take a look at the grml-live [changelog](https://github.com/grml/grml-live/blob/v0.55.1/debian/changelog).

For a detailed overview of the changes from Grml 2025.08 to 2025.12, please check out [the official release announcement](https://grml.org/changelogs/README-grml-2025.12/).
